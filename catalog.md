### Обновление плана (UI)
Добавил конкретику по «Реализация красивого и отзывчивого UI с использованием библиотеки компонентов» и интегрировал это в общий план.

### Выбор UI-стека
- Библиотека компонентов: Element Plus (устойчивый экосистемный выбор под Vue 3).
- Стили/адаптивность: Tailwind CSS (гриды, отступы, медиазапросы) + готовые темы Element Plus.
- Иконки: `@element-plus/icons-vue`.
- Нотификации/подтверждения: `ElMessage`, `ElMessageBox`.

### Гайдлайны по UI/UX
- Адаптив: макеты на контейнере `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`; сетка карточек товаров — `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4 gap-6`.
- Контраст и доступность: использовать стандартные размеры шрифтов Element Plus и Tailwind `text-base`, `text-sm`, обеспечить `:aria-label` для интерактивных иконок.
- Единая цветовая схема: активировать темизацию Element Plus (по умолчанию светлая), при необходимости добавить CSS vars для акцентов.
- Состояния загрузки/ошибок: у таблиц и форм — скелетоны (`ElSkeleton`) и лоадеры (`v-loading`). Ошибки — `ElAlert`/`ElMessage`.
- Формы: валидация фронтенда через `ElForm` rules (required, type, min для цены), отображение ошибок API под полями.
- Подтверждения: модальные окна на удаление через `ElMessageBox.confirm`.
- Пагинация: `ElPagination` снизу списка, синхронизация с query-параметрами.

### Компоненты и страницы (UI детализация)
- Базовый Layout: `AppLayout.vue`
    - Header с логотипом/названием, навигация: «Главная», «Управление товарами» (только при авторизации), «Войти/Выйти».
    - Контейнер контента и Footer, поддержка слотов для хлебных крошек/действий.
- Общие компоненты
    - `Ui/Button.vue` — враппер над `ElButton` с пресетами (`primary`, `danger`, `ghost`).
    - `Ui/Card.vue` — карточка с тенью и заголовком (использует `ElCard`).
    - `Ui/ConfirmModal.vue` — универсальная модалка подтверждения (если не используем `ElMessageBox`).
    - `Ui/Pagination.vue` — враппер над `ElPagination` с пропами: `total`, `page`, `pageSize`, события `update:page`, `update:pageSize`.
- Публичные страницы
    - `/` (ProductListPage):
        - Верхняя панель: `ElSelect` для категории, поле поиска `ElInput` с иконкой и дебаунсом.
        - Сетка карточек: `ProductCard.vue` (картинка-заглушка, название, категория, цена, краткое описание, кнопка «Подробнее»).
        - Пагинация снизу.
    - `/product/{id}` (ProductShowPage):
        - `ElDescriptions` для свойств, крупный заголовок, цена, категория, описание.
- Админские страницы
    - `/admin/products`:
        - Таблица `ElTable` с колонками: Название, Категория, Цена, Дата; действия: Редактировать (`ElButton`), Удалить (`danger`).
        - Кнопка «Добавить товар» в правом верхнем углу (primary).
        - Фильтр по категории/поиск как на публичной.
    - `/admin/products/create` и `/admin/products/{id}/edit`:
        - Форма `ElForm` с `ElFormItem`: Название (`ElInput`), Категория (`ElSelect`), Цена (`ElInputNumber`), Описание (`ElInput` type=textarea), кнопки «Сохранить», «Отмена».
        - При сохранении — `ElMessage.success` и редирект к списку.

### Техническая интеграция Element Plus + Tailwind
- Установка: `npm i element-plus @element-plus/icons-vue tailwindcss postcss autoprefixer`.
- Инициализация Tailwind: `npx tailwindcss init -p`; в `tailwind.config.js` — указать пути `./resources/**/*.vue`.
- Подключение стилей:
    - в `resources/css/app.css` — директивы Tailwind (`@tailwind base; @tailwind components; @tailwind utilities;`).
    - импорт `element-plus/dist/index.css` в `resources/js/app.js`.
- Регистрация иконок: глобально монтировать `@element-plus/icons-vue`.
- Настройка контейнера/типа шрифта в базовых классах Tailwind.

### Состояния и UX-паттерны
- Загрузка: кнопки форм в состоянии `loading` при запросах, выключать повторные сабмиты.
- Пустые состояния: `ElEmpty` для пустого списка.
- Ошибки сетевых запросов: `ElMessage.error` + inline `ElAlert` в контейнере страницы.
- Роут-гвард для админских страниц (проверка токена; 401 → `/login`).
